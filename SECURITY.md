# Security

If you find a way for a web page, another extension or anything else to read the stored key or to get codes without your consent, please report it **privately** with GitHub's "Report a vulnerability" button on the Security tab. Please don't open a public issue for it.

Never send your real setup key, a passphrase or a live code in any report or issue.

What counts:
- The key or a code reaching a page or a network request.
- Autofill on a site other than `online.tugraz.at` or `sso.tugraz.at`.
- The extension submitting more than one automatic code per login, which risks locking your token.
- A weakness in the encryption of the stored key.

Out of scope: someone with full control of your unlocked computer or Chrome profile. The README explains this.
